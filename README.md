# PythagorasMath

## Descrição
Resolvedor matemático interativo desenvolvido em Python. O sistema permite resolver 
operações matemáticas do básico ao avançado via terminal, com menu de seleção por 
conceito e validação de entradas.

## Desenvolvido por
Gabriel Oliveira

## Conceitos abordados
- Operações básicas (soma, subtração, multiplicação, divisão)
- Expressão numérica
- Porcentagem
- Equação de 1º e 2º grau e Bhaskara
- Parábola
- Regra de três
- Frações e decimais
- Potenciação e radiciação
- Sistemas de equações
- Área e perímetro
- Teorema de Pitágoras
- Média, mediana e moda
- Juros simples e compostos
- Probabilidade

## Como executar
- Python 3.10 ou superior
- Execute: `python main.py`
- Não são necessárias bibliotecas externas

## Estrutura
- `dados.py` — constantes do sistema
- `utils.py` — funções auxiliares
- `operacoes.py` — funções matemáticas
- `main.py` — menu principal
